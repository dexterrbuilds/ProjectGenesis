# Project Genesis — five-minute walkthrough

## Before presenting

Start the independent runtime and website. Verify the planner label, the operator token and the simulated-money label. Use `npm run check:llm` if real language credentials are configured; without them, say explicitly that the demo uses deterministic planning. Keep the original life database; do not reset it between presentations.

## 1. Meet Genesis

“We gave a biological brain money, language and access to the internet. Now we’re going to see what it becomes.”

Show **Live**: current activity, age, birth date, memory and capital. Explain that the birth record identifies continuous software life. Brain v1 uses the real 302-neuron C. elegans wiring diagram with simplified numerical dynamics. It is not a validated worm emulation.

## 2. Show causality

Select a saved danger decision. In **Sensory input**, inspect ASHL/ASHR and their actual injected currents. Open **Brain**, select a neuron and scrub the recorded frames. Show final readout scores, the decoded drive, the constrained planner rationale, actual action and recorded outcome.

Open **Experience** to see the next world event and its scalar channels. The next cycle consumes that event with the persistent neural snapshot. Download the full trace if a judge wants raw evidence.

## 3. Prove the wiring matters

Run `npm run demo` and show the ablation tests with `npm test`. From rest, danger leads to RETREAT and withdrawal. Removing connectivity makes downstream transmission disappear: WAIT and rest. The brain is causally upstream of the language planner. Persistent history can produce a different drive for a later danger event; that is why the trace includes snapshots.

## 4. Let a life unfold

Start **Run 8 cycles**. Genesis may research, learn, develop a project, review its resources or leave an impulse unacted upon. Recovery is an explicit product energy model, not simulated worm sleep. A quiet cycle still belongs to its experience history. Close the website, wait for configured intervals and reopen: the container runtime owns the schedule.

Show **Life** and its birth/first-experience/project/income milestones; **Memory** links back to original decisions. A saved draft is not a published business. Development-market income is simulated.

## 5. Explain the next boundary

The same identity, money and memories can retain continuity with a future brain adapter. Vercel hosts observation; Railway hosts the autonomous Node process; Postgres retains the life. A configured Solana address can be observed read-only. Real fee attribution needs the selected ClawPump provider, and spending/hiring/publication remain pending human approval.

Finish with the current activity, not a trading chart.

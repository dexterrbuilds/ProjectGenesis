# Boundary study: scientific interpretation contract

## Biological facts

The pinned file contains observed chemical contacts between proofread roots. It
supports anatomical paths, synaptic-mass retention and named/candidate recurrent
partners. It does not measure conductance, firing rate, time constant, receptor
localization, peptide volume transmission or the body's resource state. All roots
stay string-valued in JSON. Generic context is labeled by annotation, never by an
invented behavioral function. See LITERATURE.md and each frozen stage's crosswalk.

## Computational approximations

Closure rules are deterministic anatomical screening criteria. An 80% mass target
is an operational selection rule, not a physiological completeness theorem. L2
uses regional incident mass and named cell classes; L3 adds broad central context;
L4 includes the pinned proofread inventory. Added anatomy does not guarantee that
its natural afferents are active under synthetic PN current injection.

Primary comparisons preserve every original core weight, plastic edge, dopamine
operator and cue root. Added connections use contact/full-input scaling and a small
fixed recurrent gain. ACh/GABA signs use known annotations where unambiguous and
otherwise predictions. Contextual glutamate, monoamines and ambiguous cotransmission
are zero in the conservative primary. Zero fast efficacy is not absence of anatomy.
A glutamate-inhibitory variant is an explicit sign hypothesis. Added KCs have a
threshold but are not assigned new associative targets/compartments automatically.

The original kernels differ in normalization and physiological specificity. A
single graph does not resolve those differences. Stage1's positive MBON07→PAM rule
has target-specific evidence; it cannot be generalized to every MBON07 target.
Stages2/3's small effects may reflect weak effective recurrent drive and assumed
plasticity, even if anatomical retention rises. Separating mechanisms from boundary
loss is conditional on this extension model, not causal identification in a fly.

No arbitrary tonic drive, new reward label, peptide edge, novelty flag or persistence
score is introduced. Stimulation remains at original sensory/teacher neurons. The
restored network is a silent-boundary preparation, not natural olfaction/feeding.
Normalization, sign and recurrent-gain arms are reported separately. They cannot
replace failed primary effects or change a frozen stage's classification.

## Numerical and operational limits

Float64 rate updates have fixed discrete steps; all neurons update each time step.
Temporal approximations are distinct models with timing/error measurements, not
hidden skipped cycles. Clipping guarantees bounded rates but does not prove useful
stability; saturation, decay, active fractions and replay must be reported.
Generic full-brain benchmarking excludes unvalidated global plasticity; optional
frozen-kernel full-context pilots include only original supported plastic state.
Process peak RSS includes initialization and is not a steady-state cloud quote.
Snapshots of dynamic state reference immutable connectivity; they do not duplicate
all anatomy. Whole-machine energy, network latency and cloud billing are unmeasured.

## Analytically identified limitation and additive correction

The first generic operator's full-input normalization and recurrent_gain.05 bound
added incoming drive below .05 for unit-bounded rates. Added KC thresholds are .15.
Consequently those KCs cannot activate without direct current, which they never
receive. This is a model limitation, not an empirical conclusion that omitted KCs
are biologically irrelevant. The separately preregistered class-consistent arm
applies the existing PN→KC/KC→MBON-APL/APL→KC gains to known added classes across
all levels. It is an additional model assumption, not a fitted gain or changed
frozen stage. Generic results remain valid only as conservative-context results.

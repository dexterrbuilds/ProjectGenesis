## Non-equivalent evidence explicitly excluded from fitting

- Tm9 data, L1/L2 data and downstream LPLC2/descending recordings do not replace direct T4/T5 response measurements.
- Author simulation outputs (`result_cell_*`), ModelDB T4 simulation traces, paper model curves and all Stage-4/Diagnostic response tables are not empirical fitting targets.
- The [2018 T4 conductance model repository](https://github.com/ModelDBRepository/239435) provides simulation code and morphology. Its output is not new physiological validation.
- No digital threat, reward, economic or semantic labels enter any stimulus.

## Original voltage acquisition and stimulus definitions

The 2019 original input arrays contain authors' trial means after their quality-control and baseline-subtraction pipeline. The publication describes 20 kHz acquisition; the compact arrays provide 5 ms flash/moving-bar samples and 2.5 ms apparent-motion/grating samples. This study does not relabel those means as raw independent trials.

A stimulus record contains physical OFF occupancy, display-pixel positions, duration and ordering. Source angular values are approximate and depend on diagonal/cardinal trajectories and viewing position; model fits remain in the source local pixel frame. The authors' 25 ms model delay is not the stimulus onset. The supplied grating operator spans frame indices 0–24 inclusive; that convention is retained and flagged rather than silently replaced with a new stimulus. No cell-specific display timing logs were available in the compact inputs.

## Provenance and independence

`metadata/compact-acquisition.json` records bytes/SHA-256/Git blob IDs; `metadata/t5-model-tree.json` pins author inventory. Every processed train/test file is hashed in PARTITIONS.json. PLAN.md, CONDITIONAL_PROTOCOL.md, TIMING_AUDIT.md and POLARITY_PROTOCOL.md have separate dated registration hashes. FIT_FREEZE.json predates held-out scoring; PRIMARY_RESULT_LOCK.json protects its completed comparison. Acquisition failures and partial files are retained; incomplete archives are never opened as complete observations.

Source fly identities remain unknown unless explicitly documented. Repeated trials, array slots, spatial samples and time samples must not be counted as independent flies. No inferential confidence interval based on those substitutions is reported.

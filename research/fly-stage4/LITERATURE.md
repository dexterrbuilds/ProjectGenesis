## Quantitative information admitted and not admitted

The independent stimulus protocol supplies 5→60° diameter, 10°/s edge expansion, an r/v=40 ms example, contrast endpoints and the luminance-match equation. These are **stimulus measurements**, not measured response acceptance thresholds. The literature's first-few-degrees calcium detection does not identify a rate-model threshold or latency; no numerical onset PASS interval is inferred. Trial numbers and statistical tests describe the original experiment, not an error model for deterministic simulated roots.

The grating aperture, spatial period and temporal frequency reproduce a physically specified motion control (50°, 20°, 1 Hz); our local tangent-plane rendering does not reproduce the full projector geometry. Translating, displaced and temporally shuffled conditions extend the stimulus audit prospectively; no independently fitted neural target is claimed for those conditions. There is no train/validation fitting split because there is **no parameter fitting** and no compatible raw response dataset used.

LC4, LC6 and other visual projection pathways were considered. LC4 has descending relevance but a different input circuit and less directly accessible mechanism-level quantitative constraint for this small Gate-A test. It is retained in the anatomical Gate-B audit only. LPLC2 was selected for the experimentally tested radial-motion controls and LPi mechanism, not because it was previously proposed for Genesis. LC6 or LC16 would require a separate prospective mechanism and are not added after results.

## Representation / operator evidence matrix

| Decision | Classification | What is unknown or excluded |
|---|---|---|
| Real root identities, typed contact rows, hexel assignments | BIOLOGICAL FACT, within the pinned annotated reconstruction | Contact counts are not physiological weights; annotations can be wrong. |
| Direction/polarity-selective T4/T5 input channels | BIOLOGICAL FACT at class level | Root-specific tuning and physiological amplitude/time course. |
| Two-point delayed ON/OFF contrast correlation | ENGINEERING ASSUMPTION, motivated motion-detector approximation | This operator is not claimed to be the measured complete T4/T5 circuit. |
| Scalar low-pass electrical state for each selected root | ENGINEERING ASSUMPTION | Sufficient LPLC2 dendritic representation is not identified. No claim that anatomical arbor layers are independent electrical compartments. |
| Positive T4/T5→LPLC2 and T4/T5→LPi current sign | Class-level experimentally supported computational approximation | Exact root/target receptor identities and numerical gains remain unknown. |
| Negative LPi11→LPLC2 sign | Class-level experimentally supported computational approximation with published crosswalk | No measured receptor/conductance for the selected anatomical roots. |
| Negative LPi09→LPLC2 sign in L1 | HYPOTHESIS | Opposing-layer class biology does not directly validate this target-specific sign for every root. |
| All other retained rows | Unknown operator, anatomically present | Explicit zero **numerical contribution** under the model boundary is not a known zero synaptic effect. |
| Full-input or retained-effective-input normalization | ENGINEERING ASSUMPTION | Neither selected by fitting; both reported. |
| Tau, gain, lattice spacing, screen axes | ENGINEERING ASSUMPTION | No measured parameter confidence interval; tested ranges are engineering stress tests. |
| No tonic current, no plasticity, no extra local states | Declared model boundary | Does not assert that the biological circuit lacks modulation, learning or local computation. |
| Calcium/firing/behavior observation operator | Unknown | No synthetic calcium output or arbitrary action sum. |
| Genesis product mapping | NONE | No digital-world inputs, financial interpretation or semantic actions. |

The existing scalar-APL failure is not evidence that every LPLC2 must be compartmental. Conversely, choosing a scalar hypothesis here does not validate it. The experiment tests the consequences of this limited representation and must retain uncertainty if it cannot reproduce the qualitative controls.

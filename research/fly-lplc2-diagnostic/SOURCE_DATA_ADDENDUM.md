# Access-driven independent source-data audit

Registered after inspecting workbook sheet names and text headers, before reading numeric recording values. The original plan remains unchanged. No Stage-4 response table has been loaded by an estimator.

The planned Gou/Matulis/Clark Dryad file downloads returned HTTP 401 (API) and 403 (website); metadata are public but recordings are unprocessed. The original T4/T5 leave-one-fly-out comparison therefore cannot be performed here. The Gruntman Figure-2 archive is 6.32 GB and has not been processed.

Ramos-Traslosheros and Silies (2021), publisher source workbook, provides a narrower independently testable question. Sheet `Fig7g` explicitly labels Tm9 control ON/OFF mean full-field response amplitudes in dF/F0 and a control fly index. Use all finite control ROI responses, grouped by the supplied fly index; average ROIs within each fly. Compare the observation-only restriction ON response = 0 against a signed constant ON response estimated from other flies. Use leave-one-fly-out squared error, equal weight per fly, report each prediction and response. The first family has zero fitted parameters; the second has one. Do not infer a membrane/synaptic parameter or a T4/T5 fit from this comparison. A signed calcium decrement in Tm9 is not evidence for an inhibitory Tm9 transmitter. Report a paired within-fly OFF response descriptively; do not select a ratio threshold or fit to CDM state changes. Do not pool CDM and controls.

Also report descriptive FWHM measurements from explicitly labelled degree-valued sheets `Fig4j-m` and `Fig6f`. Do not infer independent fly counts where only ROI identifiers are supplied. Do not fit a RF width, retinal lattice, temporal constant or membrane model from these summaries.

If fly labels, missing-value handling or measurement definitions cannot be resolved, omit the numerical comparison rather than treating ROIs as independent flies. Source-data coefficients will not enter any frozen or new neural simulation. This is a restriction test of a precursor observation representation, not a replacement model and not an LPLC2 selectivity test.

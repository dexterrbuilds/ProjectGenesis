## 1. Question and scope

Does the frozen learned Stage-1 signal support a downstream **ordinal** conclusion that holds across declared transfer assumptions? Which conclusions instead depend on a sign, responsiveness, common-state or nuisance restriction?

The study is not intended to establish preference, approach, choice, voluntary action, general action selection, biological α1→UpWiN propagation or Genesis behavior. It must accept non-robustness, null compatibility and lack of biological inference as legitimate findings.

The narrow estimand is the **conditional downstream order set**, a subset of `{−1, 0, +1}`. These are mathematical comparison signs, not executable behavioral labels. No weighted anatomical decoder is introduced.

## 4. Estimands and units of analysis

For run r, cue c and source state s, let `x(r,c,s)` denote the unchanged saved readout. Define:

`S_D(L,R) = { sign(f(x_L) − f(x_R) + ν) : (f,ν) ∈ D }`.

Here f is a hypothetical mathematical transfer, not a fitted biological synapse. ν is an unidentified alternative-input **contrast** in an abstract output coordinate, not a new neuron, anatomical edge, injected current or physical measurement.

Four contrasts are prospectively fixed:

| Contrast | Left | Right | Interpretation limit |
|---|---|---|---|
| response_change | post | baseline | Includes unmatched nuisance in the full family |
| restoration_check | restored | baseline | Same saved model observation, not physiological reset |
| plastic_state_retention | plastic_only | baseline | Archived fast-state reset with plastic state retained |
| learned_state_comparison | post | restored | A learned-state counterfactual only under declared matched-context restrictions |

Every contrast is evaluated for both cues in all 28 runs: **224 planned units**, each reporting every transfer family. These are design counts, not observations or results. There is no pooled post-training cross-cue rank, optimized readout, effect-size ratio or post-execution normalization.

Paired and unpaired cues are both reported. Comparing arbitrary nonlinear transfers does not preserve differences of effects, so control comparisons use full ordinal profiles, not a universal magnitude subtraction.

The output sets are **marginal per-contrast identification sets**. They are not a Cartesian-product joint neural state or a distribution over outcomes. Contrasts sharing a source state also share its latent nuisance value; not every combination of marginal signs need be jointly realizable. Strict monotone control profiles hold for any common fixed map without selecting or fitting that map.

## 5. Transfer families and assumption partitions

### Evidence-admissible family

**E** is the broad family that retains every unresolved qualitative alternative: null, preserving, reversing, flat/saturated, heterogeneous, nonmonotone and context-dependent transfer, with unidentified domain compatibility and nuisance contribution. Existing acute negative responses remain observations in their original sampled domain; E does not assert that those actual recorded responses were positive or absent.

**N** explicitly allows an arbitrary finite nuisance contrast for each of the restricted maps below. Its values may depend on cue, history or learning. No finite physiological bound or independence from the learned condition is inferred.

### Restricted conditional families

Each of these holds nuisance equal across the two terms (`ν=0`) and uses the same deterministic scalar map within the contrast. This is a **matched-context counterfactual assumption**, not evidence that biological alternative input is zero.

| ID | Definition | Included limits |
|---|---|---|
| Z | Constant map | Null transfer without deleting anatomy |
| P | Any strictly increasing map | Order preservation is assumed, not discovered |
| R | Any strictly decreasing map | Order reversal is assumed, not receptor evidence |
| WP | Any weakly increasing map | Local plateaus, saturation and full flatness |
| WR | Any weakly decreasing map | Local plateaus, saturation and full flatness |
| H | Arbitrary fixed mixture of flat/responsive components; nonnegative weights sum to one; signs unrestricted | Responsive mass q spans [0,1], including endpoints and cancellation |
| U | Any fixed scalar function | Nonmonotone maps and unresolved local signs |

H's components receive the same abstract input scalar. It is not a model of actual per-cell activity, cell counts, correlations or root-specific transmission. No response probability is inferred from its weights.

The source-to-physical-state bridge, target membership, scalar sufficiency, shared map and exclusion of alternative inputs are separate hypotheses. None is silently promoted from engineering assumption to biological fact. `ASSUMPTION_PARTITIONS.json` records these distinctions.

### Engineering coverage

There is **no numerical gain, saturation, time-constant or responder-fraction sweep**. The order problem admits analytic coverage; an arbitrary finite grid would add false precision without bounding biological uncertainty.

The only new numerical precision policy is 1e−12 in dimensionless input units. Identical stored decimal values are treated as exact equality of the saved artifact. Nonzero differences within that tolerance are conservatively sign-ambiguous, not rounded to demonstrated zero. Larger differences retain their stored sign. Decimal parsing and 50-digit arithmetic are computational choices, not neural physiology or measurement accuracy.

## 6. Analytic coverage, invariance and strongest counterexamples

These are prospective mathematical rules, not evaluated Stage-5 outcomes:

- Under a fixed deterministic map and equal nuisance, identical input scalars have identical outputs.
- Strict increasing/decreasing functions preserve/reverse an ordered scalar pair; weak functions additionally permit equality.
- Distinct scalar inputs under unrestricted fixed functions or unrestricted-sign mixtures may retain, reverse or lose their order.
- Unrestricted nuisance can cancel a transferred difference or change its sign, including when source scalars are identical.

Consequently a positive conclusion must be challenged against the null map, a plateau, the opposite orientation, zero-responsive-mass mixture, cancellation and alternative-input explanation. A restricted-family singleton is not evidence that its assumptions are biologically true.

`COUNTEREXAMPLE_REGISTRY.json` predeclares adversaries for nonzero influence, direction, inhibitory interpretation, uniform response, learned-recall mediation, magnitude selectivity, reset interpretation and kinematic inference. The earlier identifiability counterexamples remain dependencies, not new simulations.

If a proposed extension cannot be covered by the frozen analytic rules, the result is UNINTERPRETABLE under this protocol until separately designed and reviewed. A finite numerical grid may not be substituted after execution. No favorable normalization or transfer family may be selected from observed outputs.

## 7. Controls and source-dependence claims

`CONTROL_MATRIX.json` includes all original primary intervention classes:

- frozen plasticity;
- silenced teaching DANs;
- removed dopamine contacts;
- single relevant DAN and matched opposite-compartment single-DAN lesions;
- PN→KC and KC→MBON route removal;
- APL removal;
- recurrence removal;
- PN-weight shuffle;
- unpaired teaching.

The single-DAN versus matched-DAN comparison is size matched. The opposite-compartment comparator is not declared biologically unrelated. Removing an entire output or sensory route is not pathway-specific mediation evidence. No weights are renormalized or lesions recomputed.

For P and R only, a predeclared **conditional modeled source-dependence gate** will assess whether:

1. All six intact paired-cue response-change and plastic-state-retention sets exclude zero.
2. All six intact restoration-check sets equal `{0}`.
3. The paired-cue response changes in frozen-plasticity, silenced-DAN, removed-DA-contact and unpaired controls at seed 1701 equal `{0}`.
4. Archived PN and KC baseline/post readouts in those controls and intact runs are present and stable to the engineering precision policy.
5. The required original restoration and replay evidence is intact.

The gate returns SATISFIED UNDER DECLARED CONDITIONAL FAMILY, NOT SATISFIED, or UNASSESSABLE. Integrity/missing-value failures prevent evaluation. It is not a biological-capability gate. If it fails, report which condition failed; do not adjust tolerances, exclude controls or change f.

Both cue profiles and all other interventions remain mandatory regardless of this gate. There is no invented threshold for strict cue-exclusive downstream selectivity, and no claim that a small unpaired-cue source change must vanish. The design does not treat the 28 runs as independent biological replicates: three primary model seeds and one-seed intervention coverage are disclosed.

Source changes can matter under a conditional matched map even though unmatched nuisance can reproduce an apparent difference without learned-state influence. This distinction is the object of the study, not a reason to drop nuisance.

## 8. Predeclared result semantics

Labels attach to a specified unit and scope and may coexist:

| Label | Exact use |
|---|---|
| ROBUST ACROSS DECLARED EVIDENCE-ADMISSIBLE FAMILY | A predeclared atomic sign conclusion is shared by every full-family member; a zero singleton remains a null conclusion |
| ROBUST ONLY UNDER RESTRICTED CONDITIONAL FAMILY | A named restricted family yields a singleton when the full family does not; state its assumptions and whether that singleton is zero |
| TRANSFER-SENSITIVE / NON-ROBUST | Full-family signs are not unique, or compatible branches disagree; show alternatives |
| NULL-COMPATIBLE | Zero is in the full-family set; this is not proof of biological absence |
| UNINTERPRETABLE | Integrity, schema, units, identity, source-evidence or analytic-coverage requirements fail |

UNINTERPRETABLE takes precedence over substantive inference. Otherwise the restricted, transfer-sensitive and null labels may all apply. The report must not choose one favorable label and hide the others. A robust set-valued conclusion about uncertainty is distinct from a single fixed downstream response; the machine output preserves the sets themselves.

The full-family signed-singleton category may be analytically unattainable while unrestricted nuisance remains admitted. This is an evidence constraint, not a reason to delete that branch or weaken the classification rule to obtain a positive label.

There is no global capability PASS criterion. A complete analysis reporting non-robust or null-compatible results is a scientifically legitimate completed experiment. No execution result is filled into this preregistration.
